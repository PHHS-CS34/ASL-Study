# ASL Study
ASL Study was created for Patrick Henry High School's ASL program. Our website is more streamlined compared to Quizlet and has zero ads. Furthermore, we load the ASL videos in a way that does not cause the webpage to crash, allowing students to experience better performance and the ability to use this website on their Chromebooks.
This website is compatible with computer and phone screens.

Please read the instructions below that explain how to use this website.

## Unit Selection Page
<img alt="unit selection page" src="media/UNITSELECTION.png" style="width: 30%">

On the **Unit Selection** webpage, you can select which units you would like to study; there are initially no units selected.

## Flashcard Page
<img alt="flashcards page" src="media/FLASHCARDS.png" style="width: 40%">

The **Flashcard** webpage will have shuffled flashcards that belong to all the units you selected on the **Unit Selection**/Home page. You can navigate back to the **Unit Selection** page by selecting the __Home__ button.

#### Our AI Policy
- LLMs cannot be given access to anyone's personal information.
	- Hide personal information and API Keys.
- No code generation but debugging and documentation are allowed.
	- Writing comments/documentation with AI is allowed.
	- Preferred prompts include “Lead me to the solution but limit generated code”
